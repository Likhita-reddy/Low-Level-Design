# Low-Level Design (LLD) Practice Repository

This repository contains my Low-Level Design (LLD) practice solutions implemented in Java.

The goal of this repository is to improve object-oriented design skills, understand design patterns, apply SOLID principles, and learn how to build scalable and maintainable software systems.

## Topics Covered

* Object-Oriented Programming (OOP)
* SOLID Principles
* Design Patterns

  * Strategy Pattern
  * Observer Pattern
  * Factory Pattern
  * Singleton Pattern
  * Decorator Pattern
  * Adapter Pattern
  * Builder Pattern
* Clean Code Practices
* Extensible System Design
* Interface-Based Programming

## Problems Implemented

### 1. Parking Lot System

Features:

* Multiple vehicle types
* Slot allocation
* Ticket generation
* Pricing strategies
* Extensible architecture

### 2. Ride Booking System

Features:

* Rider and Driver management
* Driver matching strategies
* Ride booking workflow
* Notification framework
* Analytics integration

### 3. (Upcoming)

* Library Management System
* Movie Ticket Booking System
* Splitwise
* Elevator System
* ATM System
* Food Delivery System

## Design Principles Followed

### SOLID Principles

* Single Responsibility Principle (SRP)
* Open/Closed Principle (OCP)
* Liskov Substitution Principle (LSP)
* Interface Segregation Principle (ISP)
* Dependency Inversion Principle (DIP)

### Best Practices

* Composition over Inheritance
* Programming to Interfaces
* Separation of Concerns
* Strategy-based Extensibility
* Loose Coupling
